# Text To Speech Converter

Browser-based text-to-speech with voice, speed and pitch controls, mobile-friendly layout, and downloads.

- **Listen / Pause / Stop** using the browser's built-in voices
- **Download text** as `.txt`
- **Generate audio file** (`.wav`) on-device with Kokoro. Works on phones. English only; first use downloads ~90 MB
- **Record tab audio** (desktop Chrome/Edge only)

Must be served over https (e.g. GitHub Pages) for the audio generation to work.
